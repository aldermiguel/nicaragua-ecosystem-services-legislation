# Nicaraguan Environmental Legislation: Ecosystem Services Screening

## Overview

This repository contains the computational workflow, source documents, and screening datasets used to identify and screen Nicaraguan legislation related to ecosystem services and associated concepts. The workflow focuses on legislation listed under the *Medio Ambiente y Recursos Naturales* thematic grouping of the *Asamblea Nacional de Nicaragua* legislative repository.

The workflow was implemented in Python and consists of four main scripts:

1. `01_discover_legislation.py` — discovers legislation records and saves their metadata.
2. `02_download_legislation.py` — downloads the corresponding HTML documents.
3. `03_transform_html_files.py` — transforms the downloaded HTML documents into cleaner HTML files for subsequent in-depth content analysis.
4. `04_screen_legislation.py` — screens the original downloaded HTML documents using a predefined dictionary of Spanish search terms and produces document-level and match-level screening datasets.

```text
├── 01_discover_legislation.py
├── 02_download_legislation.py

└── 04_screen_legislation.py
```

### Data directories

- `data/legislation/html/`: original HTML documents retrieved from the Asamblea Nacional legislation database and metadata output generated by the web-scraping procedure. These files are used as the input corpus for automated text-matching.
- `data/legislation/clean_html/`: transformed HTML versions of the retrieved documents. These files are retained for subsequent in-depth content analysis and are not the input to the automated screening script.
- `data/legislation/screening/`: document-level and individual-match outputs generated by the screening procedure.

Both CSV and Excel versions of the datasets are provided.

## Requirements

The workflow requires Python 3.13.15 and the external packages listed in `requirements.txt`.

The scripts also use modules from the Python standard library.

## Reproduction

From the repository root, install the required packages:

```bash
pip install -r requirements.txt
```

Then execute the scripts in sequence:

```bash
python scripts/01_discover_legislation.py
python scripts/02_download_legislation.py
python scripts/03_transform_html_files.py
python scripts/04_screen_legislation.py
```

The discovery and download stages depend on the availability and structure of the *Asamblea Nacional de Nicaragua* website. The downloaded HTML files included in the repository provide the source corpus used for the screening procedure and therefore preserve the documents retrieved during the web-scraping procedure.
