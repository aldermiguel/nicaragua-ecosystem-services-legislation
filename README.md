# Nicaraguan Environmental Legislation: Ecosystem Services Screening

## Overview

This repository contains the computational workflow, source documents, and screening datasets used to identify and screen Nicaraguan legislation related to ecosystem services and associated concepts. The workflow focuses on legislation listed under the *Medio Ambiente y Recursos Naturales* thematic grouping of the *Asamblea Nacional de Nicaragua* legislative repository.

It accompanies the article *From fences to payments: A systematic review of Nicaragua's legal framework on ecosystem services* (Alder M. Contreras).

The workflow was implemented in Python and consists of four main scripts:

1. `01_discover_legislation.py` — discovers legislation records and saves their metadata.
2. `02_download_legislation.py` — downloads the corresponding HTML documents.
3. `03_transform_html_files.py` — transforms the downloaded HTML documents into cleaner HTML files for subsequent in-depth content analysis.
4. `04_screen_legislation.py` — screens the original downloaded HTML documents using the dictionary of Spanish search terms in `search_terms.csv` and produces document-level and match-level screening datasets.

Two helper scripts complete the workflow: `run_all.py` runs the stages in order, and `build_manifest.py` records a checksum of every downloaded document. Settings shared by all scripts (website address and file locations) are kept in `config.py`.

### Data directories

- `data/legislation/discovered_legislation.csv`: metadata of every record found by the web-scraping procedure (identifier, title and relative URL).
- `data/legislation/html/`: original HTML documents retrieved from the Asamblea Nacional legislation database, one file per record, named by its `document_id`. These files are used as the input corpus for automated text-matching.
- `data/legislation/clean_html/`: transformed HTML versions of the retrieved documents. These files are retained for subsequent in-depth content analysis and are not the input to the automated screening script.
- `data/legislation/screening/`: document-level and individual-match outputs generated by the screening procedure.
- `data/legislation/search_terms.csv`: the dictionary of Spanish search terms, with their categories and tiers.
- `data/legislation/manifest.csv`: size and SHA-256 checksum of every HTML document, to verify that the corpus is unchanged.

Every column of these datasets is described in [`data/legislation/CODEBOOK.md`](data/legislation/CODEBOOK.md).

The CSV files are the reference version of each dataset. The Excel files are copies provided for convenience.

The HTML documents were retrieved in 2026 and added to this repository on 17 September 2026. The repository website may have changed since then.

## Requirements

The workflow requires Python 3.13.15 and the external packages listed in `requirements.txt`.

The scripts also use modules from the Python standard library.

## Reproduction

Install the required packages:

```bash
pip install -r requirements.txt
```

To reproduce the screening from the HTML documents included in this repository (no internet connection needed):

```bash
python scripts/run_all.py --offline
```

To repeat the whole workflow, including discovery and download from the website:

```bash
python scripts/run_all.py
```

The scripts can also be run one by one, in numerical order, for example `python scripts/04_screen_legislation.py`. They can be started from any folder.

The discovery and download stages depend on the availability and structure of the *Asamblea Nacional de Nicaragua* website. The download stage skips documents that are already present, so the included HTML files are kept as the source corpus used for the screening procedure.

### Expected results

| Stage | Result |
|---|---|
| Records discovered (`discovered_legislation.csv`) | 746 |
| Documents screened (laws, decrees and regulations) | 492 |
| Candidate documents (at least one search term found) | 47 |
| Individual matches (`screening_matches.csv`) | 322 |
